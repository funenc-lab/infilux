# Product

## Register

product

## Users

Infilux serves software engineers who coordinate multiple AI coding agents across Git repositories and worktrees. They need to switch among parallel tasks without losing repository, branch, session, editor, or terminal context.

## Product Purpose

Infilux provides a worktree-first desktop workspace for creating, running, reviewing, and recovering parallel agent-assisted development flows. Success means users can immediately understand their active repository and worktree, preserve isolated runtime context, and move between tasks without accidental cross-worktree state leakage.

## Brand Personality

Calm, precise, and operational. The interface should feel mature and trustworthy under sustained use, with a restrained premium character earned through clarity and responsiveness rather than decoration.

## Anti-references

Avoid generic consumer productivity dashboards, marketing-style card layouts, decorative AI imagery, cyberpunk effects, excessive gradients, ornamental motion, and interfaces that hide familiar developer-tool affordances behind novelty.

## Design Principles

1. Keep the active repository, worktree, session, and panel context legible at a glance.
2. Preserve workflow state across navigation while maintaining strict worktree isolation.
3. Favor dense, scan-friendly controls and predictable developer-tool interactions.
4. Make status and next actions explicit without decorative noise.
5. Optimize for repeated keyboard and pointer workflows with fast, stable feedback.

## Accessibility & Inclusion

Core workflows must be keyboard operable with visible focus, clear selected and active states, practical contrast, and no meaning conveyed by color alone. Motion must be purposeful and respect reduced-motion preferences. Dense layouts must retain readable hierarchy, stable alignment, and safe truncation across supported themes and panel widths.
