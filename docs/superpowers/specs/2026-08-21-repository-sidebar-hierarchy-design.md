# 仓库侧栏层级与渐进加载设计

## 目标

优化树形侧栏中的“最近项目”“所有仓库”和仓库分组，使用户在高密度列表中快速识别并列区块、分组归属和当前选中项目。保持完整的项目名称、路径和状态信息宽度，不使用层级缩进。

## 范围

- 树形侧栏中的最近项目区块、所有仓库区块和仓库分组。
- 最近项目的折叠状态与显示数量设置。
- 仓库列表的“加载更多”和滚动触底自动加载。
- 项目行的选中提示。

不改变仓库选择语义、工作树展开语义、分组数据模型或侧栏顶部上下文区域。

## 视觉层级

“最近项目”和“所有仓库”是同一级区块，使用相同的全宽一级标题结构：相同高度、图标槽、计数位置、圆角和弱背景面。两个区块通过统一的垂直间距和低对比度分隔线区分。

分组位于“所有仓库”区块内，保持全宽对齐，不使用左侧缩进。分组标题使用较弱背景、较低强调度和可折叠箭头，与一级标题区分；项目行作为第三层直接位于分组下方。

当前选中项目只在项目行上体现：整行提高背景对比度，增加细内描边，并同步提高名称、图标和摘要的对比度。选中提示不依赖顶部摘要、不强制展开区块，也不使用粗色条。

## 交互与状态

### 最近项目

- 最近项目标题可折叠，折叠状态持久化。
- 设置页新增“侧栏”偏好区，提供“最近项目显示数量”选项：4、8、12、16。
- 设置立即作用于最近项目列表，并通过现有设置存储链路持久化。
- 搜索或仅显示活跃 Agent 工作树时，最近项目区块不额外截断匹配结果。

### 渐进加载

- 原有“再显示 N 个”文案统一调整为“加载更多”。
- 可见加载控制会在用户向下滚动并接近其底部时自动加载一批，避免依赖点击。
- 保留可聚焦、可点击的“加载更多”按钮，作为键盘和自动加载不可用时的等价操作。
- 自动加载每次进入触发区域只加载一批，直到用户继续向下滚动，避免短列表一次性展开全部仓库。

### 分组与选中

- 分组继续独立折叠并持久化现有折叠状态。
- 折叠不会触发选择变化；若选中项目被折叠隐藏，不在其他位置复制当前项目摘要。
- 项目行的选中提示在最近项目和所有仓库中的同一仓库上保持一致。

## 实现结构

1. 在模块化设置状态中新增经过边界校验的最近项目显示数量字段和 setter。
2. 扩展仓库可见性 Hook，使最近项目采用设置值而不是固定初始数量。
3. 将加载控制演进为可复用的手动与滚动触底加载组合，避免在侧栏组件内复制观察器逻辑。
4. 在树形侧栏中维护最近项目的独立折叠状态，并复用现有本地持久化模式。
5. 在共享 `control-*` 样式层中新增一级区块、二级分组和选中项目行的语义样式；不在组件中散落主题色值。

## 扩展点

- 显示数量选项可在设置模型中扩展，而不会改变可见性策略的调用协议。
- 渐进加载控制可被 columns 侧栏或其他长列表复用。
- 侧栏区块样式通过 `data-*` 语义区分，后续可添加其他一级区块而不复制 CSS。

## 测试

- 设置字段的默认值、非法值回退和持久化。
- 可见性 Hook 对不同最近项目数量、选中项目和活跃项目的行为。
- 最近项目折叠、分组折叠、加载更多和自动加载的组件交互。
- 选中项目在最近项目与分组列表中的视觉语义与可访问性标记。
- 既有侧栏布局、键盘导航和窄宽度截断回归。

## 假设

- “显示数量”仅配置最近项目的初始显示数量；其他仓库列表继续使用渐进加载策略。
- 所有可见列表仍需支持键盘操作，因此自动加载不取代明确的手动加载入口。
- 本次不对 columns 布局新增最近项目区块；共享加载控件和选中样式可在后续复用。
