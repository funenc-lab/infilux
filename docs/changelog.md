## v0.4.17 - 2026-06-09

### Fixed

- Restored Codex live subagent discovery when the local TUI log is unavailable by hydrating
  recent session metadata from Codex session files.
- Routed clipboard image paste through the agent attachment flow without requiring Escape while
  preserving normal paste behavior in editable controls.
- Kept terminal focus, IME input, and viewport refresh stable across canvas mode, floating
  sessions, and enlarged agent views.
- Improved tmux-backed agent recovery and local terminal disconnect presentation.

### Changed

- Reduced agent canvas runtime-state churn by scoping runtime subscriptions to visible and active
  canvas sessions.
- Isolated Codex runtime homes while linking shared configuration, auth, and session data into
  prepared runtime homes.
- Extended Codex, Gemini, and Claude capability MCP resolution for remote and shared provider
  settings.

### Notes

- GitHub Release assets and downloadable package links are generated by the release workflow after
  the `v0.4.17` tag is pushed.

## v0.4.16 - 2026-05-27

### Fixed

- Quoted custom Windows agent executable paths consistently during CLI detection and local
  session launch so paths under locations such as `Program Files` no longer fail to resolve.
- Extended Codex, Cursor, and Gemini provider discovery to reuse configured builtin agent
  `customPath` hints when the Electron environment does not inherit the expected Windows home
  or config variables.
- Added Windows fallback discovery for provider settings based on the user home inferred from the
  configured executable path, reducing false negatives in the Provider configuration surface.

### Changed

- Unified provider discovery hints across the settings provider list, chat session provider
  switcher, and quick action panel so all entry points read and write the same provider config
  location.
- Added `CODEX_HOME` and `GEMINI_CLI_HOME` support to local provider config discovery before
  falling back to legacy default paths.

### Notes

- GitHub Release assets and downloadable package links are generated by the release workflow after
  the `v0.4.16` tag is pushed.

## v0.4.5 - 2026-05-09

### Fixed

- Kept new agent session startup feedback visible through terminal attach and first output so
  canvas sessions no longer show a blank terminal during launch.
- Restored persistent agent session recovery so tmux-backed sessions can reconnect after restart
  without spawning unsafe duplicate sessions.
- Preserved provider session identity during delayed Codex recovery and missing-host-session flows.
- Kept recovered agent sessions from stealing the active worktree group or active session selection.
- Scoped project token usage statistics by repository so multi-repository usage is not merged into
  one project view.
- Streamed Codex token usage JSONL reads so very large session logs no longer surface
  `Invalid string length` in the token usage panel.
- Recovered renderer startup and deferred-panel error paths so failed lazy imports show recoverable
  UI states instead of blank workspaces.

### Changed

- Reduced retained-session background work by limiting hidden chat panel polling and coalescing
  session-level subagent lookups.
- Kept the last successful session subagent snapshot during temporary polling failures and added
  backoff for repeated failures.
- Improved Codex subagent tracking so live session snapshots can be reused instead of issuing
  duplicate live scans.

### Added

- Added stricter test-quality checks for source-based tests and expanded recovery, polling, token
  usage, and resource-management coverage.
- Added external URL policy validation for main-process shell opening behavior.
- Documented agent CLI prerequisites, runtime data locations, and project documentation entry
  points in the README files.

### Notes

- GitHub Release assets and downloadable package links are generated by the release workflow after
  the `v0.4.5` tag is pushed.
